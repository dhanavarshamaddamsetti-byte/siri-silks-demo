Image folder paths to add in your GitHub repository:
- images/hero-saree.jpg
- images/story-saree.jpg
- images/saree-01.jpg through images/saree-12.jpg

To add images:
1. Create a folder named images in the repository.
2. Upload your approved product images using the exact filenames above.
3. Use JPG, PNG or WebP; if using different names, update script.js and index.html.
4. Commit the files. GitHub Pages will redeploy automatically.

Before showing the demo:
- Replace WHATSAPP_NUMBER in script.js with a business-approved number.
- Confirm all product names, prices, availability, fabric claims and policies with Siri Silks.
- The current catalogue data is fictional demo data.
- This is a static frontend prototype. It does not process payments, save orders to a server, or provide autonomous AI replies.
- Do not describe the demo cart as a live checkout.

Deploy:
GitHub repository > Settings > Pages > Deploy from a branch > main > /(root).
